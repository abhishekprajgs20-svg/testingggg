# Existing-feature preservation report
Method: `diff -r` of the original ZIP against this project. Result: only `package.json`(version), `capacitor.config.json`, `electron/main.cjs`, `electron/preload.cjs` and `src/main.js` differ; `src/main.js` has exactly 4 modified original lines (version string, MORE_TABS, render() map, merge-restore line) plus additions. All other original files are byte-identical. Existing data keys (`quizinox_local_v1`, play/AI usage/cache) are untouched; new data is an optional `db.upsc` object created on first use, so old data loads unchanged and no migration can lose records.
Note: the supplied source contains no dedicated "PYQ" or "Notes" module. PYQs are therefore handled as ordinary quizzes/questions (Question Search, Mock tests) and "notes" as the Mistake Notebook, revision items and the notes generator; the new modules link to those.
